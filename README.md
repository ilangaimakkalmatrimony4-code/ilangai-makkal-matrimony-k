# Ilangai Makkal Matrimony Android starter project

## What this contains
- A basic Android app screen with Tamil and English labels.
- GitHub Actions workflow to build a debug APK automatically.
- No `gradlew` wrapper is needed because the workflow installs Gradle.

## Upload to GitHub
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload the *contents* of the extracted folder (not the ZIP itself and not an extra enclosing folder).
5. Commit the files to the `main` branch.
6. Open **Actions** and wait for **Build Ilangai Makkal Matrimony APK** to finish.
7. Open the successful run and download the artifact named `Ilangai-Makkal-Matrimony-APK`.

This is a starter app. Registration, profile search, database, photos, payments, and website integration still need to be added.
